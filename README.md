# Business Assistant V2.5.1 — Data Ingestion

## Status

✅ Stable Release

Version: V2.5.1

---

# Overview

Business Assistant V2.5.1 is the production data ingestion workflow responsible for monitoring Gmail, understanding incoming business documents using AI, extracting structured information, preventing duplicates and storing business data for future retrieval.

This workflow serves as the foundation of the Business Assistant platform.

---

# Primary Responsibilities

- Monitor Gmail continuously
- Generate AI summaries
- Classify incoming business emails
- Extract structured business information
- Prevent duplicate records
- Store structured records in PostgreSQL
- Synchronize data to Google Sheets
- Apply Gmail labels automatically
- Send transport request notifications

---

# Supported Document Types

- Transport Requests
- Quotations
- Invoices
- Receipts

Unknown emails are ignored safely.

# Duplicate Detection

The workflow prevents duplicate processing using:

- Gmail Message ID (unique_key)

Business-level validation:

Transport Requests
- Reference Number

Quotations
- Quote Number

Invoices
- Invoice Number

Receipts
- Receipt Number
